# Code of Conduct

## Purpose
This project is maintained as a professional engineering space. We expect clear, respectful, and constructive collaboration from everyone.

## Expected Behavior
- Use respectful language in issues, pull requests, discussions, and reviews.
- Focus feedback on technical outcomes, not personal traits.
- Prefer concrete, reproducible arguments (logs, tests, code references).
- Assume good intent and ask clarifying questions before escalating.
- Help keep documentation and runbooks accurate when behavior changes.

## Unacceptable Behavior
- Harassment, abuse, hate speech, or threats.
- Personal attacks, insulting language, or intimidation.
- Publishing private/sensitive information (doxxing, credentials, tokens).
- Deliberate disruption of project workflows (spam, trolling, bad-faith edits).
- Retaliation against people who report conduct violations.

## Scope
This policy applies to all project spaces:
- GitHub issues, pull requests, reviews, and discussions.
- Linked communication channels used for project coordination.

## Enforcement
Maintainers may take any action deemed appropriate, including:
- request to edit/remove problematic content,
- warning,
- temporary restriction,
- permanent ban from participation.

Enforcement decisions are made to protect project health and participants.

## Reporting
For conduct concerns, contact maintainers privately and include:
- link(s) to relevant thread/content,
- short timeline,
- any supporting evidence.

Do not post sensitive reports publicly.
