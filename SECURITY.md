# Security Policy

## Reporting a Vulnerability
- Do not disclose security issues publicly in GitHub Issues.
- Report privately to maintainers with:
  - affected component/version
  - impact
  - reproduction steps
  - suggested mitigation (if available)

## Response Targets
- Initial acknowledgement: within 72 hours.
- Triage/impact assessment: within 7 days.
- Fix timeline depends on severity and release window.

## Scope
In scope:
- authentication/authorization bypass
- privilege escalation
- data integrity/corruption vectors
- sensitive data exposure

Out of scope:
- purely theoretical issues without practical impact
- vulnerabilities in unsupported third-party forks

## Operational Note
When sharing logs or reproduction payloads, redact tokens/secrets.
